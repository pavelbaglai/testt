# PHP 8.3 и PDO

Приложение переведено с `mysql_*` и mysqli на PDO MySQL. Общий слой находится в
`src/Database.php`: реальные подготовленные запросы, раздельная передача значений,
проверка динамических имён таблиц, буферизация результатов для старых шаблонов.
`each()` и `split()` заменены; короткие теги PHP раскрыты. Основная кодировка
осталась cp1251. Страница `dptt.php` использует отдельное соединение UTF-8.

## Локальная среда

Нужны Docker с работающим локальным daemon и Docker Compose v2.
Из корня репозитория:

```sh
./scripts/setup.sh
./scripts/test.sh
```

Скрипт собирает PHP 8.3 с `pdo_mysql`, `calendar`, `gd`, запускает MariaDB 10.11,
импортирует `__DB2__.sql` **только в пустую локальную базу** и применяет
`migrations/001_support_tables.sql`. Миграция добавляет отсутствовавшие в дампе
таблицы `statistics`, `online`, `content`, сохраняя существующие таблицы.
Повторный запуск сохраняет данные. Данные MariaDB лежат в Docker volume `db_data`.
Учётные данные в Compose предназначены исключительно для этой локальной среды;
порт базы наружу не публикуется, HTTP привязан к loopback на порту 8080.

После остановки достаточно:

```sh
docker compose up -d --no-build --wait
docker compose logs --tail 50 web
```

Тесты проверяют PHP-синтаксис, PDO CRUD, параметры с кавычками и обратными слешами,
cp1251/UTF-8, вход и попытку SQL-инъекции, основные HTTP-страницы, создание и
редактирование страницы, создание/удаление контакта, отказ в записи без роли,
обе ветви сохранения контента. Тестовые записи удаляются, прежний контент
восстанавливается. Проверки выполняются только в локальной тестовой базе;
скрипт дополнительно проверяет журнал сервера на ошибки и предупреждения.

## Другая база

Для запуска без Compose нужны PHP 8.3 и расширения `pdo_mysql`, `calendar`, `gd`.
Передайте процессу PHP переменные `DB_HOST`, `DB_PORT` (по умолчанию 3306),
`DB_USER`, `DB_PASSWORD`, `DB_NAME` (по умолчанию `telephone`) и `DB_CHARSET`
(по умолчанию `cp1251`). Пароли не хранятся в PHP-файлах. Дамп и дополнительную
миграцию импортируйте в предназначенную для приложения базу вручную.
`DB_STAT_NAME` и `DB_TRAIN_NAME` задают имена дополнительных баз (`stat` и
`train_timetable`); их схемы в репозитории отсутствуют.

Новые запросы записывайте так:

```php
$result = Database::query(Database::statement(
    'SELECT * FROM richstone_katalog WHERE id = ?',
    [$id]
));
$row = Database::fetchAssoc($result);
```

## Границы проверки

В репозитории отсутствуют CSS, изображения, каталог редактора `ed/`,
`class.phpmailer.php`, схема расписания поездов и таблицы городов из старого
примера `getuserotkuda1.php`. Для отсутствующего редактора предусмотрено обычное
текстовое поле. Внешний источник курсов `www.rw` из этой среды не проверен;
при его недоступности сохраняется имеющийся кеш.

Миграция сохраняет прежнюю модель входа (MD5 и роль в cookie). Её замена на
серверные сессии и `password_hash()` не выполнена; среда предназначена для
разработки, а готовность к публичному размещению не проверялась. Почта,
расписание поездов, отсутствующие ресурсы и все возможные ветви старого
интерфейса не входят в выполненные 43 проверки.
